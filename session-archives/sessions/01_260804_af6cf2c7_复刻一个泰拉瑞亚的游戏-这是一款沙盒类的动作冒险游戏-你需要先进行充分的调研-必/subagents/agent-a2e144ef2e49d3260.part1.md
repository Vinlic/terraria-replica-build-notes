      - 目标格 = `CreateFlow(新压力, 新阻力)`。
  - `index3 < 2`(前两次迭代)时,中心格强制 `CreateFlow(25f, 0f)`(压力源)。
  - `Swap(ref _sourceMagmaMap, ref _targetMagmaMap)`(双缓冲交换)。
- 输出 `effectedMapArea = new Rectangle(num1, num2, min1-num1+1, min2-min2+1)`(岩浆图坐标)。

### 步骤 D:ShouldUseLava(决定是否把液体变成熔岩)
- 若 `tileOrigin.Y + 100 <= WorldGen.lavaLine - 30` → false(太浅,不用熔岩)。
- 否则扫中心周围 `[-50,50)×[-50,50)` 的 100×100 区域:任一 active tile 的 type ∈ `{147, 161, 162, 163, 200}`(冰雪系)→ false。
- 否则 true。

### 步骤 E:PlaceGranite(tile/wall 写入)
- tile id:`368`(Granite Block);drunk world 时 `367`(Marble Block)。
- wall id:`180`(Granite 墙);drunk world 时 `178`(Marble 墙)。
- 对 area 内每个 IsActive 格,计算阈值函数:
  `Max(1 - Max(0, (Sin((tileOrigin.Y+top)*0.4)*0.7 + 1.2) * (0.2 + 0.5/Sqrt(Max(0, Pressure - Resistance)))), Pressure/15)  >  0.35 + (该处原地形 SolidTile ? 0 : 0.5)`
  - 满足(高压/深入岩石)→ `ResetToType(TileID.Sets.Ore[type] ? type : 368)`(保留矿石),`tile.wall = 180`(或 drunk 的 178)。
  - 否则若 `Resistance < 0.01` → `WorldUtils.ClearTile(...)`(挖空成洞),`tile.wall = 180`。
- 若 `tile.liquid > 0` 且 ShouldUseLava → `tile.liquidType(1)`(水变熔岩)。注意这一步的 `flag` 只在**满足上面任一条件后**才执行(在 if/else 内)。

### 步骤 F:CleanupTiles(去孤块)
对 area 内 IsActive 且 `WorldGen.SolidTile` 的格,数 3×3 邻域实心格数 `< 3` → 记入列表;随后统一 `WorldUtils.ClearTile(x, y, true)` 并 `tile.wall = 180`(drunk 时 178)。

### 步骤 G:PlaceDecorations(光源/装饰)
- `FastRandom fastRandom1 = new FastRandom(Main.ActiveWorldFileData.Seed).WithModifier(65440UL)`(种子决定性随机)。
- 对 area 内每个 IsActive 格(index1 = 世界 X,index2 = 世界 Y):
  - `WorldUtils.TileFrame(index1, index2, false)`、`WorldGen.SquareWallFrame(index1, index2, true)`(恒做)。
  - `fastRandom2 = fastRandom1.WithModifier(index1, index2)`(每格独立流)。
  - `fastRandom2.Next(8) == 0` 且该格 active:
    - 若下方不 active → `WorldGen.PlaceUncheckedStalactite(index1, index2+1, fastRandom2.Next(2)==0, fastRandom2.Next(3), false)`(钟乳石/石笋,方向与样式随机 3 档);
    - 若上方不 active → `WorldGen.PlaceUncheckedStalactite(index1, index2-1, fastRandom2.Next(2)==0, fastRandom2.Next(3), false)`。
  - `fastRandom2.Next(2) == 0` → `Tile.SmoothSlope(index1, index2, true, false)`(50% 概率做斜坡平滑)。

## 3. Cavinator(与这两个 biome 无关，仅供对照)

定义:`~/Project/GLM/SandboxWorld/Terarria1405/WorldGen.cs` 48733-48787 行。唯一调用点:"Mountain Caves" pass(WorldGen.cs 6628-6638),对 `numMCaves` 个 `(mCaveX[i], mCaveY[i])` 调 `CaveOpenater(i, j)` 后调 `Cavinator(i, j, genRand.Next(40, 50))`。

算法 `Cavinator(int i, int j, int steps)`:
- `num1 = genRand.Next(7, 15)`(基础半径)。
- 水平方向 `num2 = genRand.Next(2)==0 ? -1 : 1`。
- 迭代次数 `num3 = genRand.Next(20, 40)`。
- 初始位置 `(i, j)`;初始速度 `(num2, genRand.Next(10,20)*0.01f)`。
- 循环 `num3` 次:
  - 挖掘框:`[X - num1*0.5, X + num1*0.5] × [Y - num1*0.5, Y + num1*0.5]`,clamp 到 `[0, maxTilesX]` / `[0, maxTilesY]`。
  - 有效半径 `num8 = num1 * genRand.Next(80, 120) * 0.01`(即 0.8~1.2 倍)。
  - 框内满足 `Sqrt(dx²+dy²) < num8*0.4`、`TileID.Sets.CanBeClearedDuringGeneration[type]`、`type != 53`(沙)→ `tile.active(false)`(挖空)。
  - `pos += vel`;
  - `vel.X += genRand.Next(-10, 11)*0.05; vel.Y += genRand.Next(-10, 11)*0.05`;
  - clamp:`vel.X ∈ [num2-0.5, num2+0.5]`,`vel.Y ∈ [0, 2]`。
- 递归:`steps > 0` 且 `(int)pos.Y < rockLayer + 50` 时,以新位置递归 `Cavinator(x, y, steps-1)`。
