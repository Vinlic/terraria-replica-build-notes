2026-08-19 用户报"水体动态渲染:半格方块浸润未处理 + 效果与原版不一致"。

## 根因(flag5 自身格液体)
原版 `DrawTile_LiquidBehindTile`(TileDrawing.cs:3943-3963)有 **flag5**:
`tileCache.liquid > 0 && num4 != 0 && (num4 != 1 || liquid > 160)` —— 半砖/
坡面格【自己格内】的液体也画浸润(水搁在半砖上存进半砖格)。我们的
drawLiquidBehindTilesOnly 只读四邻、从不读本格 = 整类缺失(用户主报)。
blockType(num4):0=整块/1=半砖/2-5=坡面。

## 同轮修复的家族差异(逐条对照源码)
1. y0 门(:4084-4087):`上格无液 && (num4!=0 || !SolidTile(上))` → 从格顶画;
   旧版漏 `num4!=0 ||` = 半/坡面带矮 4px。
2. 坡面边角门(:4155-4162):slope4 左侧无液无实心 / slope3 右侧同 → 整带不画。
3. 半砖+上格有液+有墙 → 整带不画(:4148-4151,地下半砖水由水体本体呈现)。
4. 蜂蜜 alpha 恒 1(:4141 max(0.5×1.7,1))。
5. 致动幽灵格不画浸润(:3906 !active() 同族;wire&32)。

## 水波缝(2026-08-19 傍晚,用户报"波动时表层格与下层格之间一条明显的缝")
**真根因 = 表面静态带源窗越界采到带尾透明 padding**:Misc_water_N 的表面带
(Y=1280)仅 16 行内容(0-1 亮线/2-3 过渡/4-15 纯色体),**1296 起全透明**;波
把表层格四边形拉高(dWy<0)时源高=目标高>16 → 采样越过 1296 → 交界处 1-3px
透明行,背景透出成"缝"。修 = `waveSrcH = min(drawSh, sh)` 源高钳带内容,
多出的目标高以 ≤25% 纵向拉伸吸收(带内仅顶 4px 有结构,纯色体拉伸不可感知)。
**排查弯路两连**(方法论教训):①"底边钉整数"数学恒等式=无效修补(底边本来
就不动);②"光栅器对浮点 y/h 分别取整"假设——整数化后仍有 85 缝证伪。定位
靠的是:命中现场 dump 蓝度剖面(3 行 dim 带)+ 直接解剖贴图两带行色(表面带
1296 透明实锤)。检测探针:scripts/_wave-seam.mjs(强制 ±4px 分数位移注入
sampleDisplace;88 缝/125 列帧 → 修复后 0)。附带保留整数矩形化(顶边取整/
底边恒波前整数)。dist:index-DhU9FRei。
