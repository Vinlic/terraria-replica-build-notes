# 树冠摆动接缝 + Tree_Tops 帧表（2026-08-17）

- 原版 DrawTrees(:8184-8460) **无接缝专项处理**：密封性=公式自带（sway 偏移 (2s,2|s|) 下压 + 绕底中 0.08s 旋转；±25px 中带内上抬<下压恒覆盖）。三 case 锚/origin/偏移本仓逐项一致；GetWindCycle(:7800) 同构。
- 本仓真实风险=全局 `imageSmoothingEnabled=false` 下旋转贴图边缘**整像素跳脱**（Retina DPR2/小数对齐高发）→ 风摆图层绘制期间开 true（XNA SpriteBatch=线性，同构），静态路径保持最近邻。探针五族×全周期×亚像素相位×DPR2 零缝验证。
- **treeTopSize 坑**：`floor(w/3)−2` 只对 3 帧表成立；style 3（神圣 738×142=9帧 80×140）/19（9帧 120×140）被推成 244/364 宽三联冠——已加权威表（WorldGen FoliageData 出参 :62814-63060）+ 神圣 i%3 帧推进(+3/+6)。**帧表布局先量 PNG 宽高除以帧步长，勿假设 3 帧**。style 15/20/21 多行表 crownStyleFor 不可达未接。
- 干顶件=(88,*) 列（顶 16px 全宽实心+底 4px 空，由下件 20px 上溢覆盖）；中段件 (0,66) 20px 全高——摆开露出的是正确的宽顶件美术。
- 枝-干楔形缝（±0.087rad 楔口 ±1.7px）原版同样存在，1:1 保留勿"修"。
- 探针方法论：相机钉位=每帧回钉玩家位置（相机 lerp 会漂走致采样出屏）；探针默认 DPR=1 测不出 Retina 丢像素，须 deviceScaleFactor:2；内部 tile id≠原版 id（tree=内部key，非 5）。
