# 一人军团方法论:大规模保真工程的 AI 治理体系

> 提炼自 SandboxWorld 工程(2026-08-05 ~ 08-16,24 会话/450 亿 tokens/29 万行/位级对齐原版)。
> 适用问题类:**存在权威参照系的大型软件工程**——闭源系统复刻/移植/重写,规模超出任何单上下文,且"像"不够、要"同"。

---

## 0. 三条第一性原理(方法论的地基)

模型的一切失败模式,都能归约到这三条;方法论的全部构件,都是为了对抗它们:

1. **模型的默认输出是"最似是而非的近似"**——它会自信地滑向"看起来对"而不是"就是对的"(mulberry32 替代 UnifiedRandom、"顺手修正"原版笔误、liquidType+1 被"优化")。质量不是模型属性,是外部压力的产物。
2. **单上下文装不下真系统**——工程智能必须外置:记忆文件、工件档案、裁判程序、检查点哈希。模型只负责"当下的工匠",系统智能长在仓库里。
3. **人类的价值不在写码,在"判不对"**——一句话立项 + 高频的"不对"+ 证据包,是全工程最高杠杆的输入。把人留在判断环上,别拉进执行环。

## 1. 五层体系

### L0 · 北极星层:可证伪的目标
- 目标必须能被机器判定:"同一种子生成逐格相同的世界",而不是"尽量像泰拉瑞亚"。
- 强目标注入:用 /goal 类机制让"没达标不许停"成为会话的硬约束。
- **反例即教训**:目标模糊时,军团会生产"教堂形状的布景"。

### L1 · 标杆层:权威源的三源互证
- 铁律:**凡异常,先查标杆再动手**——反编译源码(按版本取最终态,不抄中间版本,官方 changelog 仲裁)、独立实现(TEdit)、真实产物(.wld 存档)三方互证。
- 标杆本身要升级维护(1405→1456 反编译、差异总纲落盘),并识别标杆自身的坑(dotPeek 空壳方法、反编译 artifact)。
- 一切移植锚到源码行号(cs:11159-11472),让"抄错了"永远可定位。

### L2 · 裁判层:自建验收仪,且裁判也要被验证
- **Oracle 原则**:不信任任何"看起来对"的实现,建立程序化对账(反射真二进制的 RNG、逐 pass FNV-1a 哈希检查点、金标 JSON)。
- **裁判互证**:oracle 输出 worldSurface=337 与真实存档头 groundLevel=337 精确一致,才信任裁判本身——共同误读会造成"双绿假阳性"(本工程真实发生过)。
- 金标测试是回归门:任何外部改动合入后必跑(防并行会话互相破坏)。

### L3 · 军团层:会话分工 + 记忆接力
- **一域一会话**:按子系统切分战线(世界生成/对账/UI/音频/性能…),单会话单上下文吃透一个域。
- **结构化跨会话记忆**:每份记忆带 frontmatter(归属会话/类型/一句话钩子)+ 索引页;记忆=新会话的肩膀,不是日记。
- **正式交接仪式**:上下文耗尽前触发收口轮(终扫、遗留项移交、续接会话)——接力不靠运气靠流程。
- **撞车协调**:划定禁区(他人正在改的文件/共享契约字段),越界前登记;共享常量(如 flags 位布局)的变更必须广播。

### L4 · 治理层:把教训变成制度
- 每次事故 → 一个防再犯工件(不是一句"下次注意"):run-diag 看门狗、orphan-reaper 定时收割、E2E 冻结构建、debug-report 一键导出。
- **三态近似审计**:代码库里"近似"只允许三种状态——✅1:1 / 📋精确依赖登记(带源码论证)/ ❌回炉。禁止无登记的近似。
- **一切落盘**:决策文档、版本差异总纲、算法说明、会话档案、展示页——工件是组织记忆,聊天记录不是。

## 2. 核心循环(每日节奏)

```
人类:目标注入(/goal)+ 验收("不对"+ 证据包:截图/debug-report/存档)
  ↓
军团:并行会话推进(标杆→移植→金标测试)
  ↓
冲突:金标回归门拦截 ← 并行撞车在这里暴露
  ↓
根因:回标杆源码逐行核对(绝不凭感觉修)
  ↓
沉淀:修复→测试→记忆文件→工件更新
  ↓
日终:逐 pass 哈希/统计对账(消息量/token/代码曲线——工程的心电图)
```

## 3. 人类操作手册(你的最高杠杆动作)

1. **一句话立国**:给出可证伪的北极星,而不是需求清单。
2. **高频说"不对",且带证据**:截图、debug-report JSON、坏档存档——把直觉变成模型可解析的数据。
3. **在关键时刻立铁律**:"凡异常先查源码""不要近似""遗留的也要补齐"——一句话改变全工程的失败模式。
4. **掌舵转向**:基准版本切换、对齐标准升级("像"→"位级")、范围裁剪——方向决策永远不要外包给模型。
5. **允许工程自我治理**:批准它给自己修护栏(测试冻结、进程收割),治理层是复利。

## 4. 反模式清单(43 坑的结晶,按危害排序)

1. 凭直觉修视觉/逻辑 bug → 树冠、棕榈树、瀑布帧全修错方向;**先回标杆**。
2. 信任单一标杆源 → 反编译空壳、oracle 双绿假阳性;**三源互证**。
3. 无登记的近似 → 近似债务利滚利;**三态审计**。
4. 并行会话裸改共享面 → 撞车、双实例、HMR 互殴;**禁区+契约+回归门**。
5. 长任务无看门狗 → 孤儿进程烧核数小时;**一切后台执行物必须有超时和收割**。
6. 用"聊天记录"当档案 → 上下文一炸知识蒸发;**落盘即信仰**。
7. 抄中间版本的数值 → 回退性改动会抄到错误值;**只取最终态,changelog 仲裁**。
8. 语义直译陷阱(JS 位运算 int32/浮点循环索引/+1 编码)→ **跨语言移植建立 csCompat 语义层,坑清单进记忆**。

## 5. 适用边界

- ✅ **有权威参照系**(可反编译/可对账/有金标):复刻、移植、协议实现、大规模重构——方法论全效。
- ⚠️ **参照系部分存在**(有规范无参考实现):L0/L3/L4 仍有效,L2 裁判层降级为"测试金字塔+属性测试"。
- ❌ **无 ground truth 的纯创造**(新产品/艺术):oracle 缺位,本方法论退化为普通项目管理;此时人类品味成为唯一裁判,瓶颈回到人。

## 6. 一句话总结

> 给模型图纸、验收仪和工头,它能在十二天建出一座与大教堂逐位相同的教堂;
> 缺任何一样,它会给你建一个教堂形状的布景,并为自己的作品深深自豪。
